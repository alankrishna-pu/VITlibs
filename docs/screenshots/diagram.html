3. CORE DATA STRUCTURES & ALGORITHMS (Authoritative In-Memory Engine)
Authoritative Array
• Seat g_seats[256]
• Contiguous memory allocation
• Cache-friendly sequential traversals
• Total Capacity: 256 seats
DJB2 Hash Table (O(1))
• hash = ((hash << 5) + hash) + c
• Modulo 101 prime bucket capacity
• Case-insensitive alphanumeric keys
• Instant exact seat lookup by ID
Separate Chaining
• SeatNode* buckets[101]
• Singly-linked overflow chains
• Resolves hash collisions dynamically
• 34 collisions across 112 loaded seats
Linear Search Filter (O(N))
• Multi-attribute predicate matching
• Filters by Floor, Category, Status
• seat_find_matches() engine
• Deterministic O(N) worst-case time
▼ File I/O Synchronization (Atomic Persistence) ▼
4. PERSISTENCE & STORAGE TIER (CSV Storage Engine)
Persistent CSV Store: data/seats.csv
• Header schema: id,floor_id,category,zone,status,grid_row,grid_col
• 112 individual library seats mapped across 5 floors (Ground through 4th Floor)
Atomic Write Protection
• In-memory update reflected instantly
• Full CSV rewrite on status modification
• Crash recovery & data integrity
